# Bilgisayara kaydet (çok basit)

Proje burada: https://github.com/ykslaksoy/arac-ozellik-bakim  
(Önce GitHub’a giriş yapın: ykslaksoy hesabı)

## Yöntem 1 — Zip indir (en kolay)

1. Telefonda veya bilgisayarda bu linki açın:  
   https://github.com/ykslaksoy/arac-ozellik-bakim
2. Yeşil **Code** butonuna basın
3. **Download ZIP** deyin
4. İnen zip’i açın
5. Klasörü **Belgelerim / Documents** içine taşıyın
6. Klasör adını `arac-ozellik-bakim` yapın
7. Cursor’da **File → Open Folder** ile bu klasörü açın

## Yöntem 2 — Bilgisayarda komut

PowerShell veya Terminal:

```
cd Documents
git clone https://github.com/ykslaksoy/arac-ozellik-bakim.git
```

Sonra Cursor’da `Documents/arac-ozellik-bakim` klasörünü açın.
