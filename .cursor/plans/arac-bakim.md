# Araç Özellik Bakım — İlk sürüm planı

## Kapsam
Kişisel kullanım: kendi aracınızın özellikleri + bakım takibi.
Hesap zorunlu değil; veri tarayıcıda (localStorage).

## Menüler
Ana Sayfa · Araçlarım · Bakım · Hatırlatıcılar · Ayarlar

## Veri
- Araç: plaka, marka, model, yıl, yakıt, güncel km, şasi no, motor, renk
- Bakım: tür, tarih, km, ücret, not, sonraki bakım (tarih/km)
- Hatırlatıcı: başlık, araç, tarih ve/veya hedef km

## Yapım sırası
1. Türkçe kabuk (menü + sayfalar)
2. Araç ekle / listele / düzenle / sil
3. Bakım kayıtları
4. Hatırlatıcılar
5. Ana sayfa özeti (yaklaşan bakım, güncel km)

## Senkron
Kaynak GitHub’da tutulmalı (`arac-ozellik-bakim`).
Masaüstü: clone + Cursor’da aç.
Telefon Cloud Agent: aynı repo ile başlat → push/pull.
